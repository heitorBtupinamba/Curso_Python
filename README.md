# 🐍 Exercícios de Python - Curso em Vídeo (Gustavo Guanabara)

Repositório com exercícios do **Mundo 1** do curso de Python do Gustavo Guanabara.

## 🌍 Mundo 1

### ✅ Exercício 1: Olá, Mundo!
Crie um programa que escreva **"Olá, Mundo!"** na tela.

### 🙋 Exercício 2: Respondendo ao Usuário
Faça um programa que leia o **nome de uma pessoa** e mostre uma **mensagem de boas-vindas** personalizada.

### ➕ Exercício 3: Somando dois números
Crie um programa que **leia dois números** e **mostre a soma** entre eles.

### 🔍 Exercício 4: Dissecando uma Variável
Faça um programa que **leia algo pelo teclado** e mostre na tela:
- O **tipo primitivo** do valor;
- Todas as **informações possíveis** sobre ele (se é numérico, alfabético, etc).
